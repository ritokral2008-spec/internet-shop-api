🛒 InternetShop API

Учебный backend-проект интернет-магазина, созданный на ASP.NET Core Web API для изучения backend-разработки и современных технологий .NET.

На текущем этапе реализовано API для управления товарами (Products API). Проект будет постепенно расширяться до полноценного backend интернет-магазина.
